# Pierres de France

Un site statique (HTML/CSS/JS, sans dépendances de build) présentant l'histoire de l'architecture française à travers une frise chronologique interactive, de l'Antiquité gallo-romaine à l'architecture contemporaine.

## Structure

- `index.html` — page unique du site
- `css/style.css` — styles
- `js/script.js` — interactions (filtres par style, animation au scroll, menu mobile)

## Lancer en local

Aucune installation nécessaire : ouvrez `index.html` dans un navigateur, ou servez le dossier avec un serveur statique, par ex. :

```bash
python3 -m http.server 8000
```

puis rendez-vous sur `http://localhost:8000`.
